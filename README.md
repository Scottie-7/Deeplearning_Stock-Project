# Deep Learning Stock Project - Data Pipeline
**Author:** Scottie Dunnavan

This repository contains the dataset specifications and data collection/preprocessing engine for LOB (Limit Order Book) deep learning models. This serves as the data-ingestion component of the Stock Project (see `report_ps3.pdf` in the repo root for full context).

## Repository Layout
- `data/data.txt`: Dataset download links (FI-2010, Databento, self-recorded).
- `src/`: Python source code for data streaming, collection, and preprocessing (Market Data Engine).
- `report_ps3.pdf`: Stage 3 project report.

---

## Market Data Engine (`src/`)

### Status
Early-stage, under active development. **Tastytrade L1 polling is functional** — it authenticates live and prints real quotes to the terminal. **Webull and Moomoo adapters are placeholders**, not yet implemented. This is currently a terminal proof-of-concept confirming API connectivity; it does not yet write to the Parquet-based recording pipeline described in the project report.

### File Structure

| File | Purpose |
|---|---|
| `main.py` | Entry point. Prompts for a ticker, authenticates with Tastytrade, streams live quotes to the terminal. |
| `providers/base.py` | `MarketDataSource` — the abstract interface every provider adapter implements (`connect`, `stream_data`). |
| `providers/tastytrade.py` | Tastytrade OAuth2 + REST polling implementation. Working. |
| `providers/webull.py` | Placeholder — not yet implemented. |
| `providers/moomoo.py` | Placeholder — not yet implemented. |

### Setup & Execution

1. **Navigate to source and configure environment:**
   ```bash
   cd src
   python -m venv venv
   source venv/bin/activate  # On Windows: .\venv\Scripts\activate
   pip install aiohttp websockets python-dotenv rich
   ```

2. **Configure API Credentials:**
   Create a `.env` file in the `src/` folder. *Note: This file is git-ignored. Never commit your credentials.*
   ```env
   TASTY_CLIENT_ID=your_client_id
   TASTY_CLIENT_SECRET=your_client_secret
   TASTY_REFRESH_TOKEN=your_refresh_token
   TASTY_ENV=production
   ```
   *Obtain these from Tastytrade's Manage → API → OAuth Applications. The refresh token is generated by clicking "Create Grant" on your OAuth app.*

3. **Run the Engine:**
   ```bash
   python main.py
   ```
   Enter a ticker when prompted (defaults to `IWM`). Live bid/ask/last/volume will print to the terminal roughly once per second.

### Known Limitations
- Terminal display only — no persistence to disk yet.
- Access tokens expire after 15 minutes; long sessions need a refresh-on-401, not yet implemented.
- Webull and Moomoo adapters are stubs.

### Roadmap
